# Prompt for generating the Benefit (בנפיט) logo

Copy everything below the line into Codex (or any capable code/image model). It asks for a
production-ready SVG wordmark + icon, on-brand with the website we've built.

---

You are a senior brand designer. Create a clean, modern, production-ready **SVG logo** for a
company called **Benefit** (Hebrew: **בנפיט**). Output valid, self-contained SVG code (vector
paths, no external assets), plus short notes on usage.

## About the company (so the mark fits the brand)
Benefit is an Israeli company that acts as an **integrator ("מתכלל")** — a single, trustworthy
address that takes full responsibility for solving complex, multi-disciplinary problems for
private homeowners and small–medium businesses. They plan AND execute, from first assessment
to final handover. Two core areas of expertise:
1. **Restoration of buildings** after fire, water, flood and damp damage.
2. **Consulting & process optimization** for businesses (LEAN / Kaizen / Six Sigma).
The core brand promise is **trust and accountability** in a field where customers are usually
reluctant to trust professionals: "one phone call, and we take it from here."

## Brand personality
Trustworthy, professional, modern, welcoming, calm, precise. NOT playful, NOT childish,
NOT corporate-cold. Slightly rounded / friendly geometry is welcome, but keep it grown-up.

## Deliverables
1. **Primary wordmark**: the Hebrew word **בנפיט**, set as a bold, confident, slightly rounded
   sans-serif. Hebrew is the PRIMARY language (this is a Hebrew-first brand). Reproduce the
   letters as vector outlines/paths (do not rely on a system font being installed).
   - Reference typeface for the shapes: **IBM Plex Sans Hebrew, weight 700** (the site font).
   - Match that character: even stroke weight, engineered but humane, tight but legible spacing.
2. **Secondary Latin wordmark**: **Benefit** (same spirit, for the future English site).
3. **Icon / app mark**: a simple, memorable symbol that reads as an **integrator / hub** —
   several elements converging into one center point (four short strokes meeting a central node
   works well, and doubles subtly as a "+", i.e. added benefit). It must stay legible at 16px
   (favicon) and work inside a rounded square app tile.
4. Provide these variants: (a) white wordmark on the brand blue, (b) white on deep navy,
   (c) brand-blue wordmark on white, (d) the icon alone in a rounded-square tile.

## Exact colors (use these hex values)
- Benefit Blue (primary): `#0077B6`
- Midnight (deep navy): `#03045E`
- Azure (accent): `#00B4D8`
- White: `#FFFFFF`
The signature look is **white on Benefit Blue**. No gradients in the logo itself; keep it flat.

## Constraints
- Hebrew is right-to-left — set בנפיט correctly, letters in proper order and connection.
- Deliver crisp vector paths, a sensible `viewBox`, and no raster images.
- Give me the raw SVG for each variant, and a one-line description of when to use each.
- Keep it timeless and simple enough to embroider, emboss, and shrink to a favicon.

Return the SVGs first, then the usage notes.
